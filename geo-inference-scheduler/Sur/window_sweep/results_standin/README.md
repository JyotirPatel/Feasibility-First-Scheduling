# Sur / window_sweep / results_standin

**Owner:** Sur. This is the result bundle of the earlier sweep on the **stand-in simulator** (`../../standins/`), written by `../run_sweep.py --simulator standin` before Parikshit's simulator existed. It is described in `../RESULTS_standin.md`.

It is **superseded** by `../results/` (Parikshit's simulator) and is kept only for the record. It was made with the earlier reward scale (energy cost $0.0002), so re-running it now gives slightly different numbers. Do not edit these files by hand.

| File | Contents |
|---|---|
| `runs.csv` | one row per run: settings and metrics |
| `summary.csv` | mean and 95 % bootstrap CI over seeds, per policy setting × scenario |
| `curves.csv.gz` | mean smoothed goodput G(t), per policy setting × scenario |
| `manifest.json` | git commit, config hashes, versions, command |
| `tables.md` | every table of `../RESULTS_standin.md`, generated by `../make_tables.py` |
| `figures/` | every figure, generated by `../make_figures.py` |
